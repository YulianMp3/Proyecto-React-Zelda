🗡️ The Legend of Zelda: To-Do App (React Edition)

¡Bienvenido al Diario de Misiones de Hyrule! Esta es una aplicación web interactiva desarrollada en React inspirada en el universo de The Legend of Zelda, creada como proyecto práctico y demostrativo.

✨ Características Principales

⚔️ Gestión de Misiones: Permite añadir nuevas tareas clasificándolas en Misiones Principales o Misiones Secundarias.

🎨 Sistema Visual Temático:

Las misiones pendientes se destacan en color amarillo.

Las misiones cumplidas se marcan automáticamente en color verde.

Las tareas descartadas se gestionan en color rojo.

🎵 Ambiente Musical: Reproductor integrado con el tema musical clásico de la saga (Saria's Song / Lost Woods) utilizando la Web Audio API.

💾 Persistencia de Datos: Utiliza localStorage para que tus misiones no se borren aunque cierres o recargues el navegador.

📱 Diseño Responsivo: Interfaz moderna y adaptada tanto para computadoras como para dispositivos móviles con efectos visuales tipo Glassmorphism (Tailwind CSS).

🛠️ Tecnologías Utilizadas

React (JSX / Hooks)

Tailwind CSS

Lucide Icons

Web Audio API

🚀 Cómo Ejecutar el Proyecto Localmente

Si deseas clonar y probar este proyecto en tu computadora, sigue estos pasos en tu terminal:

# 1. Clona el repositorio
git clone https://github.com/YulianMp3/Proyecto-React-Zelda.git

# 2. Entra a la carpeta del proyecto
cd Proyecto-React-Zelda

# 3. Instala las dependencias
npm install

# 4. Inicia el servidor de desarrollo
npm run dev
